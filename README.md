# 🌿 Ayurvedic Medical Center Channeling System – Frontend

The client-side web application for the **Hela Osu Weda Gedara** Ayurvedic Medical Center Channeling System. Designed with a clean, responsive interface for patients to browse doctors, book appointments, and interact with an AI-assisted inquiry feature.

🔗 **Backend Repository:** [Ayurvedic-Medical-Center-Channeling-System](https://github.com/AsiniKaru/Ayurvedic-Medical-Center-Channeling-System)

---

## ✨ Features

* **Online Channeling:** Browse available Ayurvedic doctors, filter by specialty/schedule, and book appointments online.
* **AI Assistant Interface:** Interactive chat interface connected to the backend Gemini API for patient inquiries.
* **Admin / Doctor Dashboard:** Manage bookings, schedules, and doctor profiles.
* **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

* **Core:** HTML5, CSS3, JavaScript
* **API Communication:** Fetch API / RESTful integration with Spring Boot backend
* **Media:** Cloudinary-hosted assets
